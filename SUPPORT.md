# Getting help

- **Using Sous:** start with the [README](README.md), then the guides in
  [`docs/`](docs): [installing and running](docs/running.md),
  [getting recipes in](docs/importing.md), and
  [AI agents and the API](docs/agents.md).
- **Questions, ideas, or how it's working for you:** use the
  [feedback form](https://github.com/sroberts/sous/issues/new?template=feedback.yml).
- **A recipe site didn't import:** use the
  [import form](https://github.com/sroberts/sous/issues/new?template=import-failed.yml)
  with the link.
- **Something's broken:** use the
  [bug report form](https://github.com/sroberts/sous/issues/new?template=bug.yml).
- **Security problems:** report privately; see [SECURITY.md](SECURITY.md).

Sous has one maintainer, so replies can take a few days.
